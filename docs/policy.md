# AI 使用与学术规范政策

> **Allowed with disclosure**
> 本课程允许并鼓励在合理范围内使用生成式 AI 工具，但**必须如实披露**。

## 核心原则

> "教 GenAI 的课，禁止用 GenAI 是矛盾的。" — Prof. Seongjin Choi, UMN

✅ **允许**：用 GenAI 协助完成作业、调试代码、生成文档
❌ **禁止**：完全代写、用 AI 完成"展示能力"的核心任务
📋 **必须**：如实披露使用情况

## 允许 vs 禁止

### ✅ 允许
| 场景 | 披露要求 |
|---|---|
| Cursor/Copilot 写 boilerplate | 代码注释标注 |
| 让 GPT-4 帮你 debug | 附原始报错 + AI 建议 |
| 让 LLM 翻译文献 | 注明翻译工具 |
| 头脑风暴 | 提交 brainstorm log |

### ❌ 禁止
- 完全代写作业 / 报告
- 让 AI 完成考试
- 抄袭 AI 生成内容而不披露
- 假装 AI 观点是你自己的

## 披露规范

每次作业必须附 `.ai-disclosure.md`，包含：

```markdown
# AI 使用披露
**作业**：HW1 - 应急车辆调度
**作者**：[你的名字]
**日期**：2026-XX-XX

## 使用的 AI 工具
- ChatGPT-4o
- Cursor

## 使用场景
### 1. 代码生成（约占 30%）
- **使用**：让 Cursor 生成 R1 API 调用 boilerplate
- **修改**：重写了错误处理

### 2. Debug（约占 10%）
- **问题**：API 返回 500
- **AI 建议**：检查 API key + 调大 timeout

## 没有使用 AI 的部分
- 问题分析
- 实验设计
- 结果讨论
```

## 学术诚信

- 抄袭同学作业：0 分 + 通报
- 抄袭网络资源：0 分 + 通报
- 引用格式：**GB/T 7714—2015**

## 违规处理

| 等级 | 处理 |
|---|---|
| 轻微（未披露但影响小） | 扣 50% 作业分 + 警告 |
| 中等（未披露且有抄袭嫌疑） | 0 分 + 通报 |
| 严重（明确作弊） | 0 分 + 通报 + 教务处记录 |

---

> **核心精神**：AI 是放大器，放大的是你自己的能力。
