# 期末课程项目

> 3 人一组，从 10 个方向中选 1 个，做一个完整的研究/工程原型。

## 10 个前沿选题

| # | 方向 | 题目示例 | 关键技术 |
|---|---|---|---|
| 1 | 推理 | R1 做应急车辆调度 | 推理大模型 + 运筹 |
| 2 | Prompt | 公交投诉自动归因 | Prompt + LoRA |
| 3 | RAG | 上海交通法规智能问答 | GraphRAG + 知识图谱 |
| 4 | Agent | 交通数据分析 Copilot | LangGraph + Function Calling |
| 5 | 多智能体 | 出行方案协商 | CrewAI + SUMO |
| 6 | 多模态 | 监控视频事件结构化 | Qwen2-VL / InternVL |
| 7 | 端到端 AD | CARLA 端到端 demo | CARLA + PyTorch |
| 8 | 世界模型 | 雨天驾驶场景生成 | GAIA-1 思想 + Diffusion |
| 9 | 评测 | 交通领域 LLM 评测基准 | LLM-as-Judge + 真实数据 |
| 10 | 治理 | 算法公平性审计 | 公平性指标 + 案例研究 |

## 时间节点

- **W6**：Proposal 提交（≤2 页）
- **W10**：中期检查（5 分钟汇报 + 5 分钟 Q&A）
- **W15**：终期汇报（15 分钟 + 5 分钟 Q&A）

## 提交物

- `proposal.md`（W6）
- `mid-report.md`（W10）
- `final-report.md`（W15）
- `code/`（完整可运行代码）
- `demo-video.mp4`（≤5 分钟）
- `ai-disclosure.md`（AI 使用披露）

## 评分标准（合计 100 分）

| 维度 | 占比 | 说明 |
|---|---|---|
| 问题定义 | 15% | 问题清楚、数据真实、有 Grounded |
| 方法 | 25% | 技术选型合理、考虑对比 |
| 实现 | 25% | 代码可运行、有 demo |
| 评测 | 15% | 有量化指标、有 Grounded 证据 |
| 演示与表达 | 10% | 报告清晰、demo 流畅 |
| 团队协作 | 10% | 分工明确、Git 提交规范 |

## Grounded AI 检查项

项目必须满足以下**至少 3 项**：

- [ ] 挂真实数据集
- [ ] 有 RAG 或知识图谱
- [ ] LLM 输出可追溯到来源
- [ ] 有评测 benchmark
- [ ] 有用户/专家反馈循环
