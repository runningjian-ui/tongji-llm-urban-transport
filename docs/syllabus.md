## 课程目标

完成本课程后，学生应能够：

1. **理解 LLM 工作机理**：Transformer、SFT、RLHF/DPO
2. **掌握 Grounded AI 方法**：RAG、Agent、多智能体让 LLM 扎根真实数据
3. **独立构建交通 LLM 应用**：从 Prompt 到 Fine-tune 到 Agent 全流程
4. **评测 LLM 系统**：设计交通领域评测方案
5. **批判性思考**：AI Native 范式、Grounded 原则、伦理治理
