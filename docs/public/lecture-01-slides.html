传统 vs LLM 时代

传统方式

LLM vs 传统 AI：4 个根本差异

维度传统 AILLM
数据需求大量标注少量样本甚至零样本
任务通用性单任务专用一个模型多任务

⚠️ 但 LLM 不是万能的：幻觉、实时性差、缺乏领域知识

Grounded AI

课程主线条 · 解决 LLM 的核心问题

8

什么是 Grounded AI？

AI 的输出必须 扎根真实世界——
数据、知识、上下文、人类反馈

— Prof. Jinhua Zhao, MIT

不 Grounded

LLM 自由发挥、编造事实

❌ 无法验证

Grounded

LLM 引用数据、错误可追溯

✅ 可审计

9

Grounded AI 的三层架构

数据接地

实时数据 API

路网 · 流量 · 信号

知识接地

知识图谱

法规 · 规范 · 案例

反馈接地

人在环

专家 · 市民反馈

用户问题 → LLM → 三层接地 → 有据可查的回答

Grounded 在交通的 5 个例子

场景不 GroundedGrounded ✓
"上海哪条路最堵"LLM 自由回答引用高德实时数据 API
"为什么这个配时"编造理由引用 GB 25280 + 历史日志
"事故原因是什么"通用回答检索类似事故归因报告
"方案公平吗"模糊回答接入公平性 benchmark

课堂演示

15

演示：Grounded QA

目标

让 LLM 生成"上海早高峰拥堵"分析，
每个数据点都能追溯到原始报告

步骤

  1. 准备《2025 上海交通运行报告》PDF
  2. 用 RAG 把 PDF 切片、向量化
  3. 提问："上海外滩早高峰几点最堵？为什么？"
  4. 验证：每个数据点都能找到 PDF 原文章节
结果
不 Grounded LLM 编造数据
Grounded ✓ 每个数据带 [1] 报告 P.23 引用
💻 完整代码：lectures/01-introduction/demo/grounded_qa.py
