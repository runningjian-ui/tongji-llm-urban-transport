## 课件格式

所有课件用 [Slidev](https://sli.dev) 编写，特性：
- 纯 Markdown，版本控制友好
- 支持代码高亮、LaTeX、动画
- 一键导出 HTML / PDF / PNG
- AI 友好（结构化、可解析）

本地运行：
```bash
npm run slidev:dev
```
