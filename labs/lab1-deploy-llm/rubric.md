# Lab 1 评分标准（20 分）

## 一、部署成功（5 分）

| 分值 | 评分点 |
|---|---|
| 5 | 本地成功跑通 Qwen2.5-7B，能对话 |
| 3 | 用 API 调用跑通（OpenAI/DeepSeek） |
| 1 | 跑了其他模型或更小模型 |
| 0 | 未跑通 |

| 分值 | 评分点 |
|---|---|
| 5 | 代码结构清晰、有注释、错误处理完善 |
| 3 | 代码可运行但缺乏注释 |
| 1 | 代码勉强能跑 |
| 0 | 代码不能跑或没提交 |

## 三、报告完整（5 分）

| 分值 | 评分点 |
|---|---|
| 5 | 覆盖模板所有部分、有具体例子 |
| 3 | 覆盖大部分部分 |
| 1 | 报告过于简单 |
| 0 | 未提交报告 |

## 四、思考深度（3 分）

| 分值 | 评分点 |
|---|---|
| 3 | 有独到分析、联系实际场景 |

## 评分等级

- **A** (18-20)：优秀，可作为范例
- **B** (15-17)：良好，达到要求
- **C** (12-14)：合格，基本达到要求
- **D** (10-11)：勉强通过，有明显不足
- **F** (<10)：不通过
